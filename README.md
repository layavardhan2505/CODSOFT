# CODSOFT – Artificial Intelligence Internship

This repository contains the projects completed as part of the **Artificial Intelligence Internship** at [CodSoft](https://www.codsoft.in). Each task explores a different core concept in AI, ranging from rule-based systems to search algorithms and recommendation engines.

## 📌 Tasks Completed

### Task 1: Rule-Based Chatbot
**Folder:** [`Rule-Based-Chatbot`](./Rule-Based-Chatbot)

A simple chatbot that responds to user inputs using predefined rules and pattern matching. Built using if-else logic and keyword detection to simulate basic conversation flow, without relying on any external NLP libraries.

**Concepts covered:** Natural language processing basics, pattern matching, conversational logic.

---

### Task 2: Tic-Tac-Toe AI
**Folder:** [`TicTacToe_AI`](./TicTacToe_AI)

An unbeatable AI agent that plays Tic-Tac-Toe against a human player using the **Minimax algorithm with Alpha-Beta Pruning**. The AI evaluates all possible game states to always make the optimal move.

**Concepts covered:** Game theory, adversarial search, Minimax algorithm, Alpha-Beta Pruning.

---

### Task 3: Recommendation System
**Folder:** [`Recommendation_System`](./Recommendation_System)

A recommendation system that suggests items (movies/books/products) to users based on their preferences, using **collaborative filtering** techniques to identify similarities between users or items.

**Concepts covered:** Collaborative filtering, similarity metrics, recommendation algorithms.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Concepts:** Rule-based systems, Search algorithms, Recommendation algorithms

## 🚀 How to Run
Each task is in its own folder with its own script(s). Navigate to the relevant folder and run the Python file:

```bash
cd TicTacToe_AI
python tic_tac_toe.py
```

(Repeat for the other folders, adjusting the filename as needed.)
