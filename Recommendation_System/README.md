\# Movie Recommendation System



\## Overview

This project recommends similar movies using Machine Learning.



\## Technologies Used

\- Python

\- Pandas

\- Scikit-Learn



\## Dataset

TMDB 5000 Movies Dataset



\## Features

\- Movie recommendations

\- Content-based filtering

\- Cosine similarity



\## How to Run



pip install -r requirements.txt



python app.pys
